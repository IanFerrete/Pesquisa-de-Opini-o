Objetivo do Projeto

Desenvolvido por Ian, este programa em Python foi criado para atender à campanha da empresa de marketing TudoWeb. O sistema utiliza estruturas de repetição (`for`) e decisão (`if-elif-else`) para automatizar a coleta de satisfação no atendimento de 50 clientes.



\---



Tecnologias Utilizadas

\* \*\*Linguagem:\*\* Python 3

\* \*\*Controle de Versão:\*\* Git \& GitHub



\---



Regras de Negócio e Funcionalidades

1\. Coleta o nome, idade e o código de satisfação (`1: EXCELENTE`, `2: BOM`, `3: RUIM`) de cada participante.

2\. Realiza a iteração para o total estipulado de entrevistados.

3\. Exibe ao final os totais exatos solicitados:

&#x20;  \* Quantidade de respostas \*\*EXCELENTE\*\*.

&#x20;  \* Quantidade de respostas \*\*RUIM\*\*.



\---



Como Executar o Programa



1\. Certifique-se de ter o \*\*Python\*\* instalado em seu computador.

2\. Baixe ou clone este repositório contendo o arquivo `app.py`.

3\. Abra o terminal na pasta do projeto e execute:

&#x20;  ```bash

&#x20;  python app.py

&#x20;  ```

4\. Siga as instruções inserindo os dados solicitados.
